## About Me

I am a Computer Engineer interested in the overlap between software, hardware, AI, automation, embedded systems, and cybersecurity.

I enjoy building practical systems where logic meets the physical world and creating solutions that are useful, efficient, and thoughtful.

- Software Development
- Embedded Systems and hardware integration
- AI-driven automation and voice systems
- Home automation and smart device workflows
- Cybersecurity and systems thinking
- Web development and product-focused engineering

## Currently Working On

### Offline AI Voice-Controlled Home Automation System

A smart home automation project combining offline voice interaction with Arduino-based hardware control.

The focus is on:
- offline speech recognition and voice interaction
- hardware control for home devices like lights and fans
- relay and sensor-driven automation
- Python-based backend logic
- Arduino and embedded systems integration

**Core stack:** Python, AI/NLP, Arduino, Sensors, Embedded Systems, Automation
