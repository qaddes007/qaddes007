## Currently Working On

### Offline AI Voice-Controlled Home Automation System

An advanced smart home platform combining **offline AI voice interaction** with **Arduino-based hardware control and robotics**.

**Hardware Components:**
- Arduino Uno microcontroller
- DHT11 temperature/humidity sensors
- PIR motion detection sensors
- Relay modules for device switching
- DC and servo motors for automation
- LED status indicators
- RF wireless communication

**Software Stack:**
- Python backend with Flask API
- Offline speech recognition and NLP
- Real-time voice processing
- Arduino firmware (C/C++)
- IoT device orchestration
- Sensor data logging and analytics

**Integration:**
- Home automation for lights, fans, appliances
- Environmental monitoring and alerts
- Motion-triggered actions
- Voice-commanded device control
- Mobile dashboard and remote access

**Tech Stack:** Python • Arduino • C/C++ • NLP • IoT • Robotics • Embedded Systems
