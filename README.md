## Currently Working On

### Offline AI Voice-Controlled Home Automation System

A comprehensive smart home automation platform combining **AI-powered voice interaction** with **Arduino-based hardware control**.

**Features:**
- Offline voice recognition and NLP
- Real-time device control (lights, fans, appliances)
- Environmental and motion sensors
- Text-to-speech feedback
- Arduino Uno integration with relay modules
- Python backend with Flask API
- Web dashboard for management

**Tech Stack:** Python • NLP • Speech Recognition • Arduino • Sensors • Automation
